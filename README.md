# FAQ-бот для репетиции

Терминальный бот отвечает на пять вопросов: время репетиции, команда, трек, сдача решения и призы. Вопросы и ответы лежат в [`faq.txt`](faq.txt). Бот ищет тему по ключевым словам; если совпадений нет или две темы набрали одинаковый лучший результат, отвечает «не знаю». Интернет, API и дополнительные библиотеки не нужны.

## Запуск

Нужен Python 3.9 или новее. В папке проекта выполните:

```bash
python bot.py
```

Введите вопрос, например `Как сдать решение?`. Для завершения введите `выход` или нажмите Ctrl+C. Формулировки в `faq.txt` можно обновить по объявлению организаторов: точное время, размер команды и призы в задании не указаны.
